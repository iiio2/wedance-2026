# WeDance

WeDance is a dance community platform: classes, socials and festivals city by
city, the teachers, venues and organisers behind them, and who else is going.

- **Live:** <https://2026.wedance.vip>
- **Docs:** <https://2026.wedance.vip/docs> — [quick start](https://2026.wedance.vip/docs/getting-started),
  [design system](https://2026.wedance.vip/docs/design),
  [architecture](https://2026.wedance.vip/docs/architecture) (generated from the code)
- **Contributing:** [CONTRIBUTING.md](CONTRIBUTING.md) · [Code of Conduct](CODE_OF_CONDUCT.md) ·
  [Issues](https://github.com/razbakov/wedance-2026/issues)
- **License:** [GNU AGPL-3.0-only](LICENSE)

[CLAUDE.md](CLAUDE.md).
