As a traveling dancer, I want to see when a festival's early-bird ticket is about to expire, so that I can buy before the price goes up.

## Acceptance Criteria
- My Year shows ticket alerts for festivals I've planned.
- Each alert names the festival and its early-bird offer.
- Each alert shows how many days until the early-bird price expires.
- Alerts appear only for festivals where an early-bird deadline is approaching.
- I can go from the alert to buy the ticket.
