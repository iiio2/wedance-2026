# RAZ-371 — UG 3 · Check the name: Handelsregister, IHK, WeDance trademark

**Tension.** The company name must be available and distinguishable in Munich's Handelsregister, and "WeDance" should not clash with an existing trademark.

**Do:**

* Agent: check the Handelsregister ([handelsregister.de](<http://handelsregister.de>)) for "WeDance" companies and DPMA / EUIPO (DPMAregister, TMview) for "WeDance" trademarks in classes 9, 41 and 42. Report what's found.
* Commander: ask IHK München for a free name check (Firmenrechtliche Prüfung) with the chosen name.
* Decide: register "WeDance" as a trademark now (DPMA) or later.

**Output:** a short note in `~/Orgs/WeDance` with the results, linked here.
