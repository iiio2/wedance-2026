# RAZ-424 — Sketches overview page (/sketches)

**Tension** — UI sketches live at /sketches/\* but there's no index: you can't see what's being explored, by whom, why, when, or what was decided.

**Driver** — UX decisions should be visible and traceable from sketch → decision (WeDance UX project in Linear) → user story.

**Requirement** — /sketches lists every sketch with what, why, who, when, status, decision, and links to its Linear decision ticket and story/PR. A test fails when a sketch page has no entry. Ships together with the City Battle sketch (/sketches/battle, decision ticket RAZ-416).
