# RAZ-303 — Artist profiles: one consistent layout, artist type, filterable properties

**Tension** — Artist profiles render with different layouts from one artist to the next, and don't say what the artist offers or what kind of artist they are (dancer, DJ, …).

**Driver** — An organiser or dancer has to understand at a glance why to choose this artist, and find artists by type and properties.

**Requirement** — One consistent artist profile layout (built from the visual standards / design system) that shows artist type and offering; artist browse filterable by those properties.

**Response Options**

1. Audit current artist profile variants, unify on one design-system layout, add a type field + filter facets.
2. Fold into the shared browse/filter pattern being shaped for venues.
