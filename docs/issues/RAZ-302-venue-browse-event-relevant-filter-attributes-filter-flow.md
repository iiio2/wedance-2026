# RAZ-302 — Venue browse: event-relevant filter attributes + filter flow

**Tension** — Venue browse lists thousands of venues with weak presentation and no filters; search by name/city alone is useless when one city holds huge numbers of locations.

**Driver** — An event organiser looking for a wedding/birthday/party space needs to filter by what matters for events (e.g. dance floor, mirrors, Wi-Fi, capacity), not by stay attributes like Airbnb.

**Requirement** — A defined set of event-relevant venue attributes and a filter user flow (Airbnb/Amazon-style faceted filters) on venue browse; same pattern reusable for catering, MC and DJ browse.

**Response Options**

1. Research Airbnb/Amazon facet patterns + the v4 and current SASEA venue amenities; propose attribute list + flow, then implement (committed by Mezie at the 2026-10-12 planning).
2. Start with the existing SASEA amenities as filter facets, iterate later.
